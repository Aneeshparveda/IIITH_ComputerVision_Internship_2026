# Security — IIITH Computer Vision Internship 2026

This repository contains learning code and internship coursework. It
runs locally, has no networked service, no user accounts, and stores
no credentials.

## Reporting a vulnerability

Please report security issues through a GitHub Issue in this
repository, or by email to Aneesh Parveda at aneeshparveda@gmail.com.
Do not include credentials, private keys, or personal information in
a public issue.

## Scope notes

- Do not commit API keys, tokens, or private datasets.
- Pretrained and custom YOLO weights are model files, not secrets;
  treat them as large binaries and do not add new ones in a pull
  request without agreeing it first in an issue.
