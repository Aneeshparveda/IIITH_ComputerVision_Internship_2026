# Contributing — IIITH Computer Vision Internship 2026

This repository is a personal record of work from the Online Summer
Internship 2026: video processing, YOLO object detection, segmentation,
dataset preparation, custom model training, and the ECIS final project
(electronic component detection, classification, OCR, and basic defect
analysis). It is a learning record, not a library or a service.

## What is welcome

- Corrections: typos, broken links, wrong commands, errors in a
  notebook or script, or a clearer explanation of a step.
- Small improvements: a missing requirement, a note about a version
  that changed, or a fix that keeps a week working.

## What is not welcome

- Rewriting the week structure or the internship narrative.
- Large files: datasets, videos, or model weights. Do not add binaries
  or large media to a pull request.
- Unrelated projects or new weeks.

## How to contribute

1. Open an issue first for anything bigger than a typo, so the change
   can be agreed before work is done.
2. Keep one change per pull request, and say what you changed, why,
   and how you checked it (for example, that a script still runs, or
   that a link now resolves).
3. Keep the existing week folders (`Week1_VideoProcessing/` through
   `Week5_Project/`) and the README structure intact.

## Environment

Python, FFmpeg, Ultralytics YOLO, OpenCV, EasyOCR, Label Studio, and
NumPy are the tools used across the weeks; see the README and
`requirements.txt`. Versions vary by week, so say which week and which
tool version a report is about.
